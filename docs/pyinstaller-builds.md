# PyInstaller Distribution Guide

This document follows the packaging plan in `py-3f02f1.plan.md` and explains how to bundle the MangoVoice Selenium scraper into polished executables for macOS and Windows.

---

## 1. Dependency Audit

The scraper relies on the following third-party packages:

- `selenium==4.25.0` – browser automation
- `webdriver-manager==4.0.1` – ChromeDriver management at runtime
- `requests==2.32.3` – authenticated MP3 downloads
- `beautifulsoup4==4.12.2` and `lxml==5.2.1` – HTML parsing helpers

Runtime assets generated by the app (not bundled):

- `mangovoice_scraper.log` – execution log (created next to the executable or working directory)
- `mangovoice_call_logs.csv` – CSV export
- `call_recordings/` – MP3 downloads

No additional data files need to be embedded in the binary. Chrome must be installed on the target machine; ChromeDriver is managed dynamically by `webdriver-manager`.

## 2. PyInstaller Configuration

The build configuration lives at `packaging/pyinstaller/mangovoice_scraper.spec`.

Key choices:

- Sets `pathex` to the repo root so imports resolve correctly.
- Collects all Selenium, BeautifulSoup, and WebDriver Manager submodules via `collect_submodules` to prevent hidden-import issues on Windows.
- Produces a console application named `MangoVoiceScraper`.
- Uses UPX compression when available (optional).

### Choosing a build flavor

- **One-folder (default)** – keeps dependencies extracted in a directory, faster start-up, easier to inspect.
- **One-file** – add `--onefile` to emit a single executable (extracts to a temp directory at runtime).

You can also customize:

- `icon=` – supply a `.ico` (Windows) or `.icns` (macOS) file.
- `console=False` – switch to windowed mode if you wrap the script with a GUI shim.
- Add `datas=[("path/to/file", ".")]` to ship extra resources.

## 3. Build & Verification Steps

### 3.1. Environment Preparation

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell
.venv\Scripts\Activate.ps1

pip install --upgrade pip
pip install -r requirements.txt
pip install pyinstaller==6.10.0
```

> Use the same `requirements.txt` that ships with the project to ensure the binary matches the tested environment.

### 3.2. Build Commands

**macOS**

```bash
pyinstaller packaging/pyinstaller/mangovoice_scraper.spec
# or single-file
pyinstaller packaging/pyinstaller/mangovoice_scraper.spec --onefile
```

**Windows (PowerShell)**

```powershell
pyinstaller packaging/pyinstaller/mangovoice_scraper.spec
# or single-file
pyinstaller packaging/pyinstaller/mangovoice_scraper.spec --onefile
```

Outputs land in:

- `dist/MangoVoiceScraper/` (one-folder build)
- `dist/MangoVoiceScraper.exe` (one-file build)

### 3.3. Post-build Checklist

1. **Smoke test** – run the binary from a terminal to confirm Selenium launches Chrome and manual login prompt appears.
2. **Download test** – scrape one page (use the `test_scraper.py` flow) to ensure MP3 downloads work.
3. **Log & output** – verify `mangovoice_scraper.log`, CSV, and `call_recordings` are created next to the executable (or working directory).
4. **Apple notarization** (optional) – sign and notarize the macOS binary for Gatekeeper compliance:
   ```bash
   codesign --force --deep --sign "Developer ID Application: Your Name (TEAMID)" dist/MangoVoiceScraper/MangoVoiceScraper
   xcrun notarytool submit dist/MangoVoiceScraper --keychain-profile "AC_PASSWORD" --wait
   ```
5. **Windows SmartScreen** (optional) – sign with `signtool.exe` to avoid warnings:
   ```powershell
   signtool sign /fd SHA256 /a /tr http://timestamp.digicert.com dist\MangoVoiceScraper.exe
   ```

### 3.4. Usage Guidance for End Users

- Distribute the `dist/MangoVoiceScraper` folder (one-folder) or single `.exe`/`.app` file.
- End users double-click or run from a terminal; Chrome must be installed.
- Downloads and logs appear in the run directory; instruct users to move the executable into a dedicated folder before launching if they prefer a tidy workspace.

## 4. Maintenance Tips

- Rebuild whenever `requirements.txt` changes; pinning versions ensures reproducibility.
- Periodically update ChromeDriver by re-running the bundled executable (webdriver-manager caches drivers per version).
- Keep this guide and the top-level `README` in sync with future packaging changes.
